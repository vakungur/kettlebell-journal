# Тренировочный цикл с гирей

Личный журнал трёх домашних тренировок. В каждом дне четыре суперсета. История хранится в `localStorage` на устройстве, где ты записываешь тренировку. JSON-копия переносит историю между устройствами.

## Файлы

- `index.html` — экраны и форма.
- `style.css` — оформление для телефона и компьютера.
- `app.js` — программа тренировок, история и резервные копии.
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` — установка на домашний экран и запуск без сети после первой загрузки.

## Публикация на GitHub Pages

1. На [GitHub](https://github.com/new) создай репозиторий, например `kettlebell-journal`. Для GitHub Free выбери **Public**.
2. Распакуй архив. Загрузи его содержимое в корень репозитория через **Add file → Upload files**. Для пустого репозитория используй ссылку **uploading an existing file**. Подтверди загрузку в ветку `main`.
3. Открой **Settings → Pages → Build and deployment**. Выбери **Deploy from a branch**, затем **main → /(root) → Save**.
4. После публикации открой **Settings → Pages → Visit site**. Для репозитория из примера адрес обычно выглядит как `https://ИМЯ.github.io/kettlebell-journal/`.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## На телефоне

1. Открой опубликованную ссылку в Safari или Chrome. Выбери день и нажми на название упражнения.
2. Впиши фактические значения. Повторы можно записывать по подходам или сторонам, например `Л: 10, 10, 9; П: 10, 10, 10`. Пустые поля допустимы.
3. Отметь выполненное и нажми **Сохранить тренировку**. Дата и время фиксируются при сохранении. Незавершённый ввод хранится до перезагрузки страницы.
4. В **Статистике** раскрой нужную запись. Фильтр меняет список истории. Сводка охватывает весь журнал и усредняет заполненные оценки RPE.
5. На iPhone открой меню **Поделиться → На экран «Домой»**. Если есть переключатель **Открывать как веб-приложение**, включи его. В Chrome на Android используй пункт установки или добавления на главный экран.

На iPhone история в ярлыке и Safari может храниться отдельно. Если записывал тренировки до установки ярлыка, экспортируй историю из Safari и импортируй её в приложение с домашнего экрана.

## Резервное копирование и сброс

- **Экспорт / импорт → Скачать JSON** выгружает всю сохранённую историю. На iPhone проверь папку загрузок в приложении «Файлы».
- На новом устройстве открой **Экспорт / импорт**, выбери JSON и режим **Объединить с текущими** или **Заменить данные**. При объединении записи с совпадающим ID пропускаются. Проверь режим в диалоге и подтверди.
- Кнопки удаления записи и сброса всей истории требуют подтверждения.
- Перед очисткой данных браузера сохрани JSON-копию. Не загружай личные копии истории в репозиторий.

Для проверки на компьютере можно открыть `index.html`. Для установки и автономной работы используй опубликованную HTTPS-страницу. Первый запуск должен пройти с подключением к интернету.

При обновлении приложения увеличь версию кэша в `sw.js` и загрузи изменённые файлы одним коммитом. Чтобы применить обновление после загрузки новой версии, закрой все вкладки журнала и открой его снова.
